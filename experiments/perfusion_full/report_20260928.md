# ColorPeel × ICE：完整版 Perfusion Subject + Material 实验

## 结论

论文公式层面的完整版 Perfusion 已分别训练 `<S*>` 与 `<M*>`，并完成独立及双概念生成。**当前结果不满足 identity–attribute disentanglement 目标**：red/blue 通常比旧 token-local K/V Subject 更听从普通颜色词，但源 mailbox 的圆筒与尖顶背板身份明显丢失；`<S*>` 单独使用时仍有金属外观。新 `<M*>` 能把高光金属质感带到 cube、sphere、mug，但也带来金/铜色与棚拍风格，且在 mailbox 组合中常改变物体类别或几何。现有 B0 checkpoint 不应由本实验替换。

本实验与旧 B0/P1 的训练步数、掩码和方法均不同，因此这些差异是**描述性结果**，不能单独归因于 Key-Locking、Value 限制或协方差中的某一个因素。

## 方法与边界

实现包括论文 Eq. (3) 对所有 cross-attention 文本位置的协方差度量投影与 sigmoid gate、冻结的 superclass Key 目标、每层可训练的 Value 目标、概念方向 EMA，以及 Eq. (4) 的双概念联合投影。Subject 的 superclass 为 `mailbox`，Material 为 `metal`。两个概念均独立训练后组合；没有学习自由 Subject/Material Key，也没有改动基础 SD 权重。训练仅优化每个概念的 token embedding 与 16 层 Value 目标。每份最终 checkpoint 的 optimizer 分组含 16 个 Value 参数与 1 个 embedding 参数，16 个 Key 目标只作为 buffer 保存。

100,000 条 LAION-400M shard 0 caption 构成未中心化协方差；每条 caption 固定抽取一个非特殊 contextual token。逆矩阵不需 ridge，条件数约 1,723。CLIPSeg 生成的软掩码直接作为 denoising MSE 权重。训练使用 SD 1.4、seed 42、400 步、有效 batch 16、beta 0.75、tau 0.1、Value LR 0.03、embedding LR 0.006；每 25 步保存一个 checkpoint。

论文未规定 caption token 汇聚、加权 loss 的精确 reduction、验证 prompt 与种子、CLIP 版本等全部实现细节。本项目明确采用一条 caption 的固定内容 token、每图加权空间均值、8 个固定 prompt、种子 42–49、OpenAI CLIP ViT-B/32。验证按 DDIM 50 步、CFG 6 生成，计算 8 张图平均 CLIP-I 与平均 CLIP-T 的调和平均。最初汇总脚本误用“逐图调和平均的平均”；保留原始文件为 `selection_initial_mean_of_harmonics.json`，根据已保存的逐图分数重新汇总为 `selection.json`，没有重采样或改变图像。Material 作为独立概念是项目扩展；原论文未验证 standalone material token。

## 无普通类别词与材质迁移探针

为检查 `<S*>` 自身，而非 prompt 里的普通 `mailbox` 一词，另以 `a photo of <S*>`、`a photo of a red/blue <S*>` 及其 `made of <M*>` 版本，各 seed 42–44 生成 18 张：原始 run `20260928-141104__subject_token_probe_original_18`，balanced run `20260928-141152__subject_token_probe_balanced_18`。两组均 18/18、无过滤。原始 `<S*>` 多次生成汽车、箱包而非 mailbox；balanced 多数生成普通邮筒，但源圆筒加尖顶形状仍不稳定。Material 组合也未稳定恢复源身份。审阅图在 `review/` 对应 run 的 `review/` 下。

独立 Material 迁移 run `20260928-140514__material_transfer_probe_27` 对 cube、sphere、mug 比较无材质词、普通 `metal` 与 `<M*>`，种子 42–44、100 步、CFG 3.5。27 张中 2 张被 safety checker 过滤。`<M*>` 通常能产生明显镜面高光，但偏金/铜或彩色的干净棚拍效果，与普通 `metal` 的灰银写实质感不同；mug 的把手在部分样本消失。它学到的是一组风格、颜色与材质的耦合变化，而非纯金属属性。对应图在 `review/20260928-140514__material_transfer_probe_27/review/`。

## 核查与限制

服务器上 `test_attention.py`、`test_covariance.py`、`test_prepare_soft_masks.py` 共 11 项通过，包含 CUDA autocast 回归；`compileall` 通过。实际 SD 单概念验证、双概念前向、三组训练和所有最终生成均完成。训练代码从一开始就冻结 SD、普通 token embedding、基础 K/V 权重及其余 UNet 参数；checkpoint 审计确认每份只存一个 modifier embedding、16 层 Value 参数和冻结 Key 目标。

本项目的源数据对 identity–material 分离本身有局限：源 mailbox 是现实金属制品，balanced 数据也来自单个源图及其变体。CLIP-I 对图像整体相似度敏感，不能替代源形状身份评分。Material 72 图含形状/颜色/场景偏差。因此这次结果说明**完整公式的项目应用没有达到目标**，不证明 Perfusion 原论文在其对象基准上无效。
