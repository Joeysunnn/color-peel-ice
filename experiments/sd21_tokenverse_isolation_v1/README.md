# TokenVerse-inspired concept isolation in SD2.1

This bounded experiment tests background obedience of the current Mailbox / orange /
wood-texture composition. It is an adaptation of the isolation regularizer, not a
reproduction of TokenVerse's Flux token-modulation architecture.

## Paper evidence

[TokenVerse, arXiv2501.12224v1](https://arxiv.org/html/2501.12224v1), section5 and
Figure4 (PDF pages5/7), describes a joint image/caption, a base-model teacher, and
an L2 penalty restricted to the unrelated-image half in50% of iterations.
AppendixA.2 and Figure21 (pages13/21) use25 generated image/caption pairs.
The diagram supports a shared noisy canvas and caption for teacher/student.
The paper does not supply the isolation weight, loss reduction, image resolution,
or enough details to reproduce its implementation exactly. The project page
still labels the code as forthcoming when inspected2026-11-03.

## Explicit adaptation decisions

- Keep the pinned SD2.1-base512 model and original single-image foreground
  training objectives, data, captions, optimizers and learning rates.
- Train independent LoRA rank64 control/isolation arms from the base for each of
  Subject1000, Color150 and Texture1000. Save Subject/Texture500/1000 and
  Color100/150. Both arms enable gradient checkpointing. Ordinary text rows and
  all other base-model parameters remain frozen by the existing update policy.
- Use a new fixed25-image bank generated by the same SD2.1 base with25 concise,
  diverse captions, seeds1000..1024, PNDM100, CFG3.5,512px, FP16, checker enabled.
  These generation parameters and captions are ours. Review every image/caption
  before training. The old all-beach collection is not used in this experiment.
  No filtered image is silently replaced. Avoiding the four evaluation scene
  words in the captions does not prove the visual scenes are disjoint.
- Preserve the actual augmented512x512 concept image on the left and place an
  unmodified512x512 bank image on the right. Encode the whole1024x512 canvas
  with the VAE, then sample one timestep and one noise tensor. Teacher/student
  share both. Use the positional caption template shown in Figure4.
- Student uses the live learned embedding and its usual token-local K/V gate.
  Teacher replaces the modifier ID with its one-token initializer ID and
  re-encodes the whole caption, with adapter gates zero. This removes the
  modifier's causal CLIP influence on later words as well as its K/V residual.
  No spatial gate prevents the student from affecting the right half.
- Compute squared prediction difference only on the right latent columns64:128,
  summed across channels and divided by spatial area. Weight1 is a fixed local
  choice, not an author-reported hyperparameter. Add its backward after the
  ordinary foreground backward and before one shared optimizer update.
- Choose exactly half of each branch's steps using an independent predeclared
  random subset. Do not alternate odd/even steps: the fixed16-image Texture
  order would then expose only half of its inputs to isolation. All auxiliary
  random draws, forward and backward are inside a separate RNG context.
- Test the auxiliary gradients using the old learnedS1000/C150/T1000 sources;
  those weights are used only in the probe. Formal paired training starts fresh.
  Require actual rectangular checkpointed backward, finite nonzero modifier and
  K/V gradients, frozen teacher/base parameters, preserved RNG and finite memory.

The student and teacher are the same frozen base U-Net with different text
conditioning and adapter gates. Their weights are not copied or updated during
teacher execution. The frozen ordinary rows and encoder weights are verified.
Right-half consistency can still trade concept strength for less interference;
it is not a guarantee of semantic disentanglement.

## Fixed evaluation

All inference uses ordinary square512 generation, PNDM100 / CFG3.5, seeds31/38,
empty negative prompts and the checker. No layout prompt is used for evaluation.
The112-image plan includes:

- FinalS1000/C150/T1000: all8 combinations of control/isolation branch weights,
  for street, snow, flowers and beach at both seeds (64 images).
- MidS500/C100/T500: all-control vs all-isolation for the same scenes/seeds (16).
- Subject-only final scene transfer (16), Texture-only final object transfer
  (12), and Color-only final mug/vase checks (4).

The primary comparison is fresh all-control versus fresh all-isolation, at the
same step/prompt/seed. Single-branch switches identify which branch changes the
result. Review background, Mailbox integrity, orange binding and target fine
grain separately. Two seeds are a diagnostic sample, not a success-rate estimate.
No automatic weight or prompt sweep is queued if this bounded test fails.

## Execution

Only reviewed commits are pushed to the authorized project origin and cloned
into a new server checkout. Runtime data remain outside Git. The selected
colorpeel017 environment and pinned models are unchanged.

1. `python -B -m experiments.sd21_tokenverse_isolation_v1.run --stage prepare
   --source-audit ORIGINAL_SCENE_AUDIT --output FRESH_EXPERIMENT`
2. Inspect all25 bank images/captions and record `bank_review.json` with accepted
   status, count25, manifest SHA256 and reviewer `assistant_visual_review`.
   This is an internal data-quality check, not a request for additional user
   authorization. The user authorized image selection and this experiment.
3. `python -B -m experiments.sd21_tokenverse_isolation_v1.run --stage train
   --output FRESH_EXPERIMENT`

The real probe runs first on GPU0. After it passes, Subject uses GPU0, Color GPU1
and Texture GPU2; the two arms of a branch run serially on the same GPU. All
three GPUs must be idle before launch; no existing process is stopped. The
independent branches finish before exports and final inference on GPU0.
Configs, commands, bank provenance, probe results, training metrics, exports,
source hashes, PNG hashes and every filtering label are retained.
