# Perfusion-style Subject pilot: two matched mailbox cohorts

## Question and implementation

This pilot compares the frozen token-local K/V Subject (`B0`) with a new Subject (`P1`) whose cross-attention Key at `<S*>` is the frozen base projection of the contextual `mailbox` encoding from `a photo of a mailbox`. Each cross-attention layer learns only one rank-1 Value pair `a, b`, applied only at the `<S*>` position. The selected Material token and its token-local K/V checkpoint are identical within each B0/P1 comparison. This tests the **combined** Key-Locking plus rank-1 Value constraint; it does not isolate the contribution of either component.

The original and balanced aligned cohorts were each matched to their own frozen B0 training source. P1 changed the Subject adaptation mechanism while keeping that cohort's images, masks, captions, seed 42, 5000 steps, optimizer settings, and base SD version. The balanced P1 used a second idle Tesla V100 GPU; its device choice is in the immutable run configuration snapshot. Both arms of each evaluation used the same GPU and the same prompts, seeds 42–44, CFG 3.5, and 100 sampling steps. The plain, red, and blue comparison manifests are byte-identical across the two evaluation runs (SHA-256 `58f13f969ce06918cf836d7135e848f1ea4bc34b983ca6990a6ef7f1f6e5bb5ff`).

## Answer to the pilot question

The combined P1 constraint improves ordinary red/blue prompt alignment in both matched cohorts, which is consistent with unconstrained Subject K/V carrying color information that resists prompt changes. It does **not** meet the full disentanglement goal at 5000 steps: the specific source mailbox identity degrades, Subject-only images remain metallic, and adding `<M*>` does not reliably become the main source of metal appearance. The result does not justify replacing either existing B0 checkpoint with P1.

The original cohort has a known mismatch between its red source caption and visual color. The balanced source reduces that particular ambiguity but still derives its variants from one mailbox image and background. This limits claims about identity independent of color, finish, and scene. The comparison also cannot say whether Key-Locking or the rank-1 restriction produced the observed color gain, since they changed together by design.
