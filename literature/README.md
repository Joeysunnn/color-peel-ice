## Note policy

Each note separates:

- **paper evidence**: what the authors report;
- **our inference**: bounded relevance to this repository;
- **action**: a tracked config, report, control, or measurement.

A paper result cannot confirm this experiment. Repository findings require their own immutable run path and metric source.
